# Dataset Information

## Source

This project uses Tableau's Sample Superstore dataset, a fictional retail dataset designed for learning and analysis.

Official source: [Tableau Public Sample Data](https://public.tableau.com/app/learn/sample-data)

## Purpose

The dataset is used for SQL analysis, data quality checks, profitability analysis, and Power BI dashboard development.

## Data Availability

Please obtain the dataset from the official Tableau source. The original dataset is not included in this repository.

## Notes

The analysis results depend on the dataset version and the data preparation steps used in this project.
